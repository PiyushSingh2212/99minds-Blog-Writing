# Blog Repurpose Skill

## Usage
```
/blog repurpose <file>
/blog repurpose <file> --formats linkedin,twitter,instagram,facebook
```

## 99minds Social Platforms
LinkedIn · Twitter/X · Instagram · Facebook

## Funnel-Stage Adjustments

Before writing, identify the post's funnel stage and adjust all platform content accordingly:

- **TOFU**: Focus on the insight/tip, not the product. Mention 99minds only as a brief CTA at the end (e.g., "Build yours with 99minds →"). Keep educational and shareable.
- **MOFU**: Highlight the problem-solution angle. Name 99minds features naturally as examples. CTA points to a feature page or case study.
- **BOFU**: Lead with the value proposition. Name 99minds directly. CTA is a direct trial/demo link.

## Voice Rules for All Platforms
- Conversational, jargon-free, fun
- Use contractions (it's, you'll, we're)
- Add punctuation before emojis! 😄
- No back-to-back emojis
- Address reader as "you"

---

## LinkedIn Post

Purpose: Thought leadership, B2B reach, e-commerce decision-makers

Structure:
- Hook: Bold opening line (2 sentences max before "see more" fold)
- Value: 3-5 key insights as short paragraphs or bullets
- 99minds angle: natural connection to loyalty/rewards platform
- CTA: Link to full blog post
- Hashtags: 3-5 relevant (e.g., #LoyaltyPrograms #Ecommerce #CustomerRetention #99minds)
- Length: 150-300 words

## Twitter/X Thread

Purpose: Awareness, quick tips, reach

Structure:
- Tweet 1 (Hook): Grab attention in 1-2 sentences + thread indicator ("Thread 🧵")
- Tweets 2-7: One key insight per tweet
- Tweet 8: Summary + CTA + link to blog
- Max 280 chars per tweet
- Use emojis sparingly (1-2 per tweet max)

## Instagram Caption

Purpose: Visual brand awareness, community

Structure:
- Emoji hook (1 emoji only!) + opening line
- 3-5 key takeaways (short)
- Connection to 99minds (natural, not salesy for TOFU topics)
- CTA: "Link in bio" or "Save this post!"
- Hashtags (10-15): mix of niche + broad
  - Niche: #LoyaltyProgram #CustomerRetention #EcommerceMarketing #RewardsProgram #99minds
  - Broad: #Ecommerce #OnlineBusiness #ShopifyStore #CustomerExperience
- Length: 100-150 words caption + hashtags

## Facebook Post

Purpose: Community engagement, broader audience

Structure:
- Conversational opening question or statement
- 2-3 key insights from the blog
- 99minds mention (funnel-appropriate)
- CTA + blog link
- 1-2 relevant emojis
- Length: 100-200 words
