# Blog Repurpose Skill

## Usage
```
/blog repurpose <file>
/blog repurpose <file> --formats social,email,linkedin
```

## Repurpose Formats

### Twitter/X Thread
- Hook tweet (grab attention)
- 5-7 key insight tweets
- CTA tweet with link
- Max 280 chars per tweet

### LinkedIn Post
- Professional hook (2 lines before fold)
- Key insights in bullet points
- Personal angle or story element
- CTA to read full post
- 3-5 relevant hashtags

### Email Newsletter
- Subject line (A/B variants: 2 options)
- Preview text (50 chars)
- Email body (300-400 words)
- CTA button text + URL placeholder

### Instagram Caption
- Visual hook (emoji-led)
- 3-5 key points
- Story connection to 99minds
- 5-10 hashtags

## Output
Separate markdown sections for each format, ready to copy-paste into publishing tools.
