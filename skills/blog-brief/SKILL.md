# Blog Brief Skill

## Usage
```
/blog brief <topic>
```

## Output Sections
1. **Topic Overview** — Search intent, target audience, content type recommendation
2. **Primary Keyword** — Target keyword with search volume estimate
3. **Secondary Keywords** — 5-10 supporting keywords and LSI terms
4. **SERP Analysis** — Top 5 competitor articles and their key angles
5. **Content Gaps** — What competitors miss that we can cover
6. **Recommended Structure** — H1, H2s, H3s with keyword placement
7. **Word Count Target** — Based on SERP average + 10-20% more depth
8. **Key Stats to Include** — 3-5 statistics with source suggestions
9. **99minds Angle** — How to connect topic to 99minds features naturally
10. **Internal Link Opportunities** — Related 99minds blog posts to link
11. **CTA Recommendation** — Best conversion goal for this content
