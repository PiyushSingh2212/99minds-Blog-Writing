# Blog Brief Skill

## Usage
```
/blog brief <topic or keyword>
```

## What This Generates
A complete blog brief in MD format, matching the 99minds Blog Brief Template structure. This brief becomes the input for /blog write.

## Brief Output Format
```markdown
# Blog Brief — [Topic]

- **Primary Keyword**: [main keyword from 99minds keyword tracker]
- **Topics/Terms to Mention**: [semantic keywords, related terms]
- **Audience/Tone**: Use e-commerce industry terms. Make it audience-friendly and accessible.
- **Recommended Word Count**: [based on SERP average + 10-20% more]
- **Recommended Heading Count**: [H2 + H3 count]
- **Images**: [number needed]
- **Slug**: [lowercase-hyphenated-slug]
- **Meta Title**: [60 chars max with primary keyword]
- **SE Ranking Content Optimizer Link**: [if available, paste link here]

## References
```
