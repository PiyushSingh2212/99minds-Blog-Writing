# 99minds Content Production Guide

This is your master reference for all content production rules. Always follow these when writing any blog post.

---

## Language Guidelines

| Rule | Detail |
|---|---|
| Tone | Conversational · Easy to understand · Jargon-free · Fun |
| Pronouns | Use "I"/"we" for 99minds, address readers as "you" |
| Contractions | Always use: it's, we're, you'll, don't, I'm |
| Jargon | Avoid — don't say "utilize", use "use" |
| Memes/GIFs | Don't use (exception: 99minds product GIFs) |
| Spelling reference | Merriam-Webster's Dictionary |

### Capitalization
- **Title + H2**: Title Case
- **H3 and below**: Sentence case (unless proper nouns)
- **Meta title**: 60 chars max · include primary keyword
- **Meta description**: 160 chars max · include primary keyword

### Punctuation
- **Oxford comma**: Always required
  - ✅ "You can issue store credit, loyalty points, and coupons using 99minds."
  - ❌ "You can issue store credit, loyalty points and coupons using 99minds."
- **Em dash**: NEVER USE. Replace with a comma, colon, semicolon, or hyphen.
  - ✅ "Issue gift cards, coupons, store credit, loyalty points, and membership plans - all from a single dashboard."
  - ✅ "Issue gift cards, coupons, store credit, loyalty points, and membership plans: all from a single dashboard."
  - ❌ "plans—all from a single dashboard"
  - ❌ "plans — all from a single dashboard"
- **Comma before coordinating conjunction**: NOT needed if it starts a sentence
  - ✅ "Now you can issue store credit for your refunds using 99minds!"
  - ❌ "Now, you can issue store credit..."

### Bulleted and Numbered Lists
- **No full stops (periods) after bullet points or list items**
- If a bullet has multiple sentences, end the final sentence without a period
- Use the Oxford comma when listing three or more items

### Numbers
- Spell out: one through nine
- Numerals: 10 and above
- **Exception — headers and meta descriptions**: always use numerals (e.g., "7 Best..." not "Seven Best...")
- **Exception — before million/billion**: write 1-9 numerically (e.g., "3 million customers", not "three million")
- Italicize for emphasis: "There are over *100* integrations that work with 99minds!"

### Emojis
- Always add punctuation before emojis! 🙂
- Never use two emojis back-to-back
- Go-to: 📚 😀 😃 🤩 🙌 ✨ 🌻 🛠️ 👀 👏 🚀
- Restricted (do not use): 👍 👌 😂 💔 😕 😔 😢 😭

## Competitor Prohibition

**Never name 99minds competitors** anywhere in any blog post - not in comparisons, tool lists, FAQs, or examples.

Prohibited competitors include (but are not limited to):
- Loyalty platforms: Loopy Loyalty, Smile.io, Stamp Me, Square Loyalty, Yotpo, LoyaltyLion, Fivestars, Marsello, Zinrelo, Antavo, Loyalzoo, Kangaroo Rewards
- Ecommerce platforms when used as stat sources: Shopify, Square, BigCommerce (these can be mentioned as integration partners only)

When discussing free or alternative tool options, use generic language:
- ✅ "Several platforms offer free tiers for businesses just starting out."
- ❌ "Smile.io's free plan supports up to 200 monthly orders."

**99minds is always the only named platform recommendation.**

## Stats and Research Sources

### Approved Sources (use these only)
Always source stats from recognized research organizations. Preferred sources in order of authority:

| Tier | Sources |
|---|---|
| Primary | Deloitte, McKinsey, Accenture, Bain & Company, Harvard Business Review |
| Secondary | Nielsen, Forrester Research, Pew Research Center, Statista, eMarketer, Gartner |
| Tertiary | PwC, World Bank, The Conference Board, Edelman Trust Barometer |

### Prohibited Stat Sources
- Competitor platform reports (Square Future of Commerce, Shopify data, Yotpo reports, etc.)
- Unknown or unverifiable blogs
- Stats older than 5 years unless foundational (e.g., Bain's 5%/25-95% retention stat)

### Mandatory Stat Linking
Every stat must have a linked source - no exceptions:
- ✅ `<a href="[source URL]" role="link" target="_blank">72% of consumers</a> say loyalty programs... (Deloitte)`
- ❌ "72% of consumers say loyalty programs... (Deloitte)" — text citation only, no link

Always verify the URL resolves and the stat matches before publishing.

## Cliche Phrases — Banned

Never use these phrases in any blog post:

| Banned phrase | Use instead |
|---|---|
| "game-changer" | describe the specific benefit |
| "let's dive in" | start the section directly |
| "in today's world" | state the specific context |
| "it's worth noting" | state the point directly |
| "golden word / rule" | state the concept plainly |
| "the answer lies in" | state the answer |
| "needless to say" | omit or state it |
| "at the end of the day" | state the conclusion |
| "leveraging [X]" | "using [X]" |

## Scope of Information

The scope of each blog is determined by its **funnel level**. Always check the blog brief for funnel level assignment.

### TOFU — Awareness Stage
Reader: NOT problem-aware or solution-aware. Pure brand/awareness building.
- ❌ Do NOT try to sell 99minds
- ❌ Do NOT explain the importance of products or solutions at length
- ✅ Provide maximum helpful information — explanations, strategies, types, examples, case studies
- ✅ Add FAQs sourced from AnswerThePublic, Quora, Reddit
- ✅ In conclusion only: briefly introduce 99minds as a possible option

### MOFU — Awareness + Interest Stage
Reader: Knows the problem, exploring solutions — NOT product-aware.
- ❌ Do NOT explain the importance of customer retention/gift cards/loyalty programs (the reader already knows)
- ✅ Explain different methods/approaches (types of loyalty programs, examples, case studies for inspiration)
- ✅ Introduce 99minds features naturally as implementation examples
- ✅ Propose 99minds as the solution in the conclusion

### BOFU — Consideration + Decision Stage
Reader: Problem-aware, solution-aware, method-aware — ready to pick a product.
- ❌ Avoid the basics (what is customer retention, why loyalty programs matter)
- ❌ Skip types/approaches/examples — reader knows these already
- ✅ Focus entirely on product promotion: features, pricing, ratings, reviews
- ✅ For BOFU listicles: 99minds is always the first item on the list
- ✅ Direct CTA to try 99minds

## Blog Formats

### Listicle Format
Use for: "Top 10 Best [KEYWORD]", "Best [KEYWORD] Tools", "X Best [KEYWORD] Software"

Structure:
- **Intro**: <150 words
- **H2: TL;DR — Top 10 Best [KEYWORD] At a Glance**: Table of all products + one-line conclusion
- **H2: What Should You Look for in [KEYWORD]?**: <200 words
- **H2: The 10 Best [KEYWORD] to Use in [Year]**
  - **H3: 1. 99minds** (always first)
    - Intro: talk about relevant 99minds features per topic
    - H4: 99minds best features (bullet list — most relevant only)
    - H4: 99minds limitations (1-2 real ones from reviews, not harsh — e.g., "limited review count vs larger competitors")
    - H4: 99minds pricing: Basic $49/mo · Pro $99/mo · Ultra $199/mo · Premium $499/mo · Enterprise: contact
    - H4: 99minds ratings and reviews (Shopify 5/5, 30+ reviews · G2 5/5, 5 reviews)
  - H3: 2. [Next tool] — same H4 format
  - H3: 3-10. Repeat

### How-to / Guide Format
Use for: "How to [do X]", "What is [KEYWORD]", "Guide to [KEYWORD]"

Structure:
- **Intro**: <150 words
- **H2: [Keyword] Summary** (TL;DR): <130 words
- **H2: What is [primary keyword]?** or **Why do you need [primary keyword]?**
- **H2: How to [primary keyword]** — step-by-step process
- **H2: 99minds + [primary keyword]** — show use cases and examples, any other relevant H2s
- **Conclusion**: summary + recommendation that includes 99minds (include "99minds" in the heading)

## Final Submission Checklist

Before submitting any blog post, verify every item below:

### Structure
- [ ] TL;DR section present (5-7 bullets, immediately after intro)
- [ ] Author bio block present (after last FAQ, before CTA sidebar)
- [ ] FAQ heading reads "Frequently Asked Questions" — NOT "Frequently Ask Questions"
- [ ] Minimum 6 FAQ questions, covering PAA queries from SERP
- [ ] Table of Contents includes TL;DR and FAQ entries

### Images
- [ ] Alt text provided for all images
- [ ] Hero image has `rel="preload"` and `role="img"`
- [ ] All non-hero images have `loading="lazy"`
- [ ] All images are dashboard screenshots (not homepage)

### Content
- [ ] Proper heading hierarchy (H1 → H2 → H3)
- [ ] Proper capitalization (Title Case for H1/H2, Sentence case for H3+)
- [ ] Zero em dashes anywhere in the file (search for — character)
- [ ] Zero competitor names anywhere in the file
- [ ] No banned cliche phrases
- [ ] Every H2 opens with the main point stated in the first sentence
- [ ] Oxford commas used throughout
- [ ] All prices correct: Basic $49 · Pro $99 · Ultra $199 · Premium $499 · Enterprise: contact
- [ ] Ratings: Shopify 5/5 (30+ reviews) · G2 5/5 (5 reviews)

### Stats and Sources
- [ ] Every stat has a linked source (no text-only citations)
- [ ] All sources are from approved research organizations (Deloitte, McKinsey, Accenture, Bain, HBR, Nielsen, Forrester, Pew, Statista, etc.)
- [ ] No stats sourced from competitor platforms (Square, Shopify, Yotpo, etc.)
- [ ] All source URLs verified to resolve and match the cited stat

### SEO
- [ ] Meta title provided (60 chars max, primary keyword)
- [ ] Meta description provided (160 chars max, primary keyword)
- [ ] Slug provided (lowercase, hyphenated, keyword-rich)
- [ ] All 99minds landing page links have correct anchor text ("99minds [topic]")
- [ ] Minimum 20 internal links included (15+ blog posts, 2+ landing pages)
- [ ] All links use `target="_blank"` (not `target="_blanck"`)

### Schema
- [ ] JSON-LD Article schema present (headline, description, image, author, publisher, datePublished)
- [ ] JSON-LD FAQPage schema present (all FAQ questions and answers included)
- [ ] Both schemas in a single `<script type="application/ld+json">` block at end of file
