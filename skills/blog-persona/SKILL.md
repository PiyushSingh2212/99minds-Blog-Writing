# Blog Persona Skill

## Usage
```
/blog persona create
/blog persona list
/blog persona apply <persona-name> <file>
```

## Default 99minds Personas

### Persona 1: The Industry Expert
- **Role**: Senior content strategist at 99minds
- **Tone**: Authoritative, data-driven, confident
- **Audience**: CTOs, VP Engineering, technical decision-makers
- **Vocabulary**: Technical, precise, jargon-appropriate
- **Reading Level**: Professional (Grade 12+)
- **Style**: Long-form analysis, case studies, benchmarks

### Persona 2: The Practical Marketer
- **Role**: Growth marketer who uses 99minds daily
- **Tone**: Friendly, practical, conversational
- **Audience**: Marketing managers, e-commerce operators
- **Vocabulary**: Plain English, action-oriented
- **Reading Level**: Consumer (Grade 8-10)
- **Style**: How-to guides, listicles, quick tips

### Persona 3: The Thought Leader
- **Role**: 99minds CEO/founder perspective
- **Tone**: Visionary, bold, forward-looking
- **Audience**: Founders, investors, industry peers
- **Vocabulary**: Strategic, big-picture, trend-focused
- **Reading Level**: Professional (Grade 11+)
- **Style**: Opinion pieces, trend analysis, predictions

## Custom Persona Creation
Define:
- name, role, tone_dimensions (4: formal/casual, funny/serious, respectful/irreverent, enthusiastic/matter-of-fact)
- target_audience, vocabulary_level, content_types
